## Replacing them with your own

You can retake any of these, but **use demo mode** so no personal numbers end up on the internet. On a Mac: **Cmd + Shift + 4**, press **Space**, click the browser window, then save it here with the same file name.

If you ever screenshot your real dashboard, crop or blur body weight, body fat, food and heart-rate numbers, and check for browser tabs or notifications in the shot.
